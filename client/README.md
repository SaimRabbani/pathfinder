# PathFinder Frontend

This frontend is part of the full PathFinder MERN application.

## Main stack

- React + Vite
- Tailwind CSS
- React Router
- React Hook Form + Zod
- Axios
- Recharts

## Development

Use the root project README for the full setup flow.

Important frontend environment variable:

```bash
VITE_API_URL=http://localhost:5000
```

Run the frontend only:

```bash
npm run dev
```

Build the frontend:

```bash
npm run build
```

Lint the frontend:

```bash
npm run lint
```
